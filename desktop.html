나만의 AI 비서 & 그만의 AI 비서

모든 시민에게 '나만의 AI 비서'를, 입법·사법·행정 전 기관·부서에 '그만의 AI 비서'를 배정해 업무를 실시간으로 주고받습니다.

PDV — 프라이빗 데이터 금고

출생부터 평생을 기록하는 나만의 데이터 금고. 오직 내 단말기에만 저장되어 나 외에는 누구도 접근할 수 없습니다.

교육 — 유치원부터 대학원까지

학교 제도를 보완합니다. 학습 세션을 append-only로 기록하고, Bloom 6단계 이해도를 임의로 건너뛰지 않습니다.

혼디 vs 카카오톡·일반 AI·블록체인

MoTE(소형 특화 모델 조합)로 전력 사용량 최대 96% 절감, Openhash로 에너지 소비 최대 99.8% 절감(FPGA 18.2W vs GPU 160.3W).

GDC — 화폐 하나에 은행·보험·증권 융합

위변조 불가능한 재무제표 자체가 신용이 되는 것이 목표. 현재는 서비스 결제·거버넌스 투표가 실제 동작(LIVE) 중입니다.

          📋 오류 기록 — 2026-06-25 Cloudflare DNS API
        

        

          [오류 1] code:7003 "Could not route to /zones/.../dns/records"

          원인 A: URL 경로 오타 —
          dns/records (슬래시, 틀림) →
          dns_records (언더스코어, 정상)

          원인 B: Custom API Token의 Zone Resources가 "All zones"일 때 특정 Zone 접근 불가.
          → "Specific zone → hondi.net" + "Zone:Read" 권한 추가 필요.



          [오류 2] code:9207 "Request body is invalid"

          원인: PowerShell Here-String(@"..."@)이 JSON에 개행문자(CRLF)를 삽입 → CF API 파싱 실패.

          해결:
          [System.IO.File]::WriteAllText(tmpFile, json)
          로 임시 파일 저장 후
          curl --data-binary "@tmpFile"
          로 전송.



          [최종 작동 조합]

          ✅ Global API Key (X-Auth-Key + X-Auth-Email) + endpoint: /dns_records + 파일 기반 JSON

          ❌ Custom Token → Zone routing 오류 반복

          ❌ PowerShell ConvertTo-Json / Here-String → CRLF 삽입 오류
