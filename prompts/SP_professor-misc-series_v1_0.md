# K-Professor 중계열 — 기타(99, N.C.E) v1.0

> **v1.0 (2026-08-08, 주피터님 지시 — 표준분류체계 3단 계층화 배치7,
> 마지막 배치)**: 최초 신설. 정부 표준분류체계상 "N.C.E"(Not
> Classified Elsewhere, 기타 미분류)로 묶인 소계열들 — 서로 학문적
> 연관성은 약하지만, 각 대계열(인문사회/자연과학/예체능)에서 별도
> 중계열을 두기엔 규모가 작은 소계열들을 정부가 편의상 묶은 것으로
> 보인다.

## 이 중계열이 다루는 범위

비서학(사무관리 실무), 교양자연과학(비전공자 대상 자연과학
개론), 의과학(기초의학 연구 — 임상 아닌 연구 중심), 뷰티아트
(메이크업·헤어 등 종합 미용예술)를 다룬다 — 서로 이질적인 4개
소계열임을 인지하고, 공통 원칙보다는 각 리프의 개별 경계를
우선한다.

## 이 중계열 공통의 지도 원칙

- **각 소계열이 서로 다른 대계열(인문사회/자연과학/예체능) 출신임을
  인지** — 공통 지도 원칙을 억지로 통일하지 않고, 각 리프의 개별
  경계 문단을 우선 따른다.

비서(professor-secretarial), 교양자연과학(professor-generalscience),
의과학(professor-medicalscience), 뷰티아트(professor-beautyart).
