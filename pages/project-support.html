01 — Background

개요

혼디(HONDI)는 2026년 9월 1일부터 12월 31일까지 진행되는 베타 테스트 기간 동안 ChatGPT, Claude, Gemini, DeepSeek 등 해외 LLM을 백엔드로 사용합니다. 베타 테스트 종료 시점까지, 이들 해외 LLM을 오픈소스 LLM 기반의 국내 서버로 전면 대체하는 것을 목표로 합니다.

전환의 이유

  • 데이터 주권 — 국민의 행정·사법·의료·금융 관련 질의가 해외 서버를 거치지 않도록 보장 (PDV, Private Data Vault 철학과 일치)
  • 비용 예측 가능성 — 해외 API 종량제 요금은 환율·정책 변화에 취약하며, 자체 서버는 장기적으로 총소유비용(TCO)을 고정
  • 주권 AI 인프라 — 정부·공공기관 연계 서비스인 만큼 국내 법제·데이터센터 규정 준수가 유리
  • 한국어·행정 도메인 특화 — 국내 오픈소스 모델은 한국어 및 국내 법률·행정 용어에 대한 파인튜닝 여지가 큼

전환은 베타 테스트 기간 중 병행 운영(해외 LLM + 국내 오픈소스 LLM A/B 검증) 후, 정식 서비스 전환 시점에 완전 대체하는 단계적 접근을 취합니다.

02 — Comparison

국내 오픈소스 LLM 비교

모델개발사규모(파라미터)라이선스장점단점
EXAONE 3.5 LG AI연구원 2.4B / 7.8B / 32B 비상업 연구용 무료, 상업적 사용은 LG AI와 별도 협의 KMMLU(한국어 벤치마크) 최상위권, 법률·과학·의학 도메인 추론 강점, 32K 컨텍스트, 함수 호출 지원 상업적 사용 시 라이선스 협의 필요(비용·절차 리스크), 대형(32B) 모델은 자체 서빙 인프라 부담
HyperCLOVA X SEED 네이버 0.5B / 1.5B / 3B 오픈 가중치 공개 한국어 데이터 학습량이 압도적(GPT-3 대비 약 6,500배), 국내 문화·시사 상식에 강함, 경량 모델은 온디바이스·엣지 배포 가능 오픈 공개된 버전은 상대적으로 소형이라 복잡한 추론 작업에는 한계, 초대형 플래그십은 비공개

Kanana 카카오 다양한 크기 (1.5 버전부터 오픈소스화) 오픈소스 배포 카카오 생태계(메신저·커머스) 연동 경험 축적, 지속적 업데이트 행정·공공 도메인 특화 사례 상대적으로 적음
VARCO LLM NCsoft 13B 등 자체 라이선스 대화형 시나리오·멀티턴 대화에 강점 게임·콘텐츠 도메인 중심 설계로 행정 도메인 적합도는 별도 검증 필요
Luxia (Saltlux) 솔트룩스 엔터프라이즈용 상업 라이선스 금융·법률·공공 도메인 적합도 높음(엔터프라이즈 레퍼런스 보유) 오픈소스가 아닌 상업 라이선스로 자체 서버 완전 통제에는 제약
KULLM / Polyglot-Ko 학계(고려대 등)·EleutherAI 계열 다양 오픈소스 완전한 오픈 가중치, 커스텀 파인튜닝 자유도 최대 최신 상용 모델 대비 성능 격차, 유지보수·커뮤니티 지원이 기업 모델보다 약함
1차 후보 압축 — 행정·법률 도메인 추론 강점(EXAONE 3.5 32B) + 상업 라이선스 자유도(Solar) + 한국어 상식 보강(HyperCLOVA X SEED)을 조합한 멀티모델 라우팅 구조가 유력합니다. 도메인별(입법/사법/행정 vs 일상 대화)로 모델을 분기하는 방식입니다.
03 — Cost Estimate

인프라 구축 비용 추산

혼디 사용자 100만 명 기준

아래 수치는 2026년 상반기 국내 GPU 클라우드/베어메탈 임대 시세와 자체 데이터센터 구축 사례를 참고한 추정치이며, 실제 계약 조건에 따라 변동될 수 있습니다. 정확한 산정을 위해서는 벤더 견적 비교가 필요합니다.

3-1. 가정

Assumptions
  • 혼디 등록 사용자 100만 명, 일 활성 사용자(DAU) 약 10~15%(10만~15만 명) 가정

  • 피크 시간대 동시 접속 약 3,000~5,000명 목표 처리 용량
  • 서빙 모델: EXAONE 32B급(양자화 적용) + Solar 10.7B 경량 라우팅 혼합
