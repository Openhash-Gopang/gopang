# AGY_VAULT_STORE_GAP_FIX_20260810.md

`PDV_U0-1_COMPLETION_20260810.md`(교수/전문가 페르소나 경로) 다음 배치 —
국가기관 SP 경로의 §U0-1 상태를 정확히 재조사하고, 실제로 발견된 구멍을
메운 기록.

## 정정 — 이전 턴에서 제가 드린 정보가 틀렸습니다

"`AGY_VAULT_STORE` 실행기가 없다"고 말씀드렸는데, `worker.js`를 직접
조사해보니 **2026-07-23부터 이미 구현돼 있었습니다**(`handleGovRelay`
내부, 342개 국가기관 공용 진입점). 이전 판단은 `UNIVERSAL-common` 문서의
문장만 믿고 코드를 직접 안 본 데서 나온 오류였습니다 — 문서 자체가
그 시점엔 정확했을 수도, 아니면 문서와 코드가 같은 날 어긋났을 수도
있으나, 어느 쪽이든 **문서 서술이 아니라 코드를 직접 조사했어야** 했습니다.

## 실제 발견한 구멍

기존 구현은 `canDelegate`(SP_CALL 위임이 가능한 gov_do/gov_national 최상위
두 기관)의 **첫 LLM 응답에만** 적용되고 있었습니다. 위임이 실제로
발동해서 새 LLM 응답을 받는 4개 지점(위임 거부 재합성/서브호출 실패
안내/위임 성공 최종 합성/합성 후 안전문구 대체)은 이 인터셉트를 전혀
거치지 않았습니다 — 결과:
1. 그 응답에 새로 나타난 `[AGY_VAULT_STORE]` 태그가 `owner_pdv`에
   기록되지 않음.
2. **스트립도 안 돼 태그 원문이 사용자 화면에 그대로 노출될 수 있었음**
   (기존에 알려진 "기록 누락"보다 심각한, 별도의 UX 결함 — 이번 조사로
   새로 발견).

## 수정 내역

`worker.js`에 `_interceptAgyVaultStore(env, dataObj, guid, ctx)` 헬퍼를
신설(원래 인라인으로 한 곳에만 있던 로직을 추출) — `data.choices[0].
message.content`를 제자리에서 변경하는 방식(재대입 아님, `data`가
`const`라 재대입하면 런타임 에러)이라 호출부는 반환값을 버려도 된다.

`handleGovRelay`가 반환하는 **모든** 최종 응답 직전에 이 헬퍼를 호출하도록
배선:
- 원래 위치(첫 LLM 응답) — 기존 로직 그대로, 헬퍼 호출로 교체.
- 위임 거부 재합성 응답(`data2`) — 신규 배선.
- 서브호출 실패 안내 응답(`data3`) — 신규 배선.
- 위임 성공 최종 합성 응답(`data4`, 세션 종료형 태그가 나올 확률이
  가장 높은 지점) — 신규 배선.

DEPT_TASK_REQUEST/AFFILIATION_APPROVE/AFFILIATION_REVOKE/WORK_PDV_REQUEST
4개 분기는 **손대지 않았다** — 이 분기들은 새 LLM 응답을 받지 않고 첫
응답(`firstContent`)을 그대로 재사용하며, 그 시점엔 이미 원래 위치의
인터셉트가 먼저 실행돼 태그가 스트립된 뒤이므로 구조적으로 안전함을
코드 흐름 추적으로 확인했다.

## `UNIVERSAL-common_v1_11.md` 갱신

§U0-1의 "현재 실제 구현 경로" 산문 문단을 **SP 카테고리별 상태표**로
교체 — 다음 세션이 "교수는 됐으니 이제 다 됐나?"라고 착각하지 않도록,
어느 경로가 몇 대 요건을 충족하는지 한눈에 보이게 했다. 이전의 부정확한
서술("코드가 존재하지 않는다")도 명시적으로 정정해뒀다.

## 검증

- `worker.js` 문법 검사 통과.
- `_interceptAgyVaultStore` 호출 지점 4곳(원본 1 + 위임 분기 3) grep으로
  재확인 — `handleGovRelay`의 모든 `return new Response(...)` 중 새
  콘텐츠를 담은 지점은 전부 커버됨.
- `guid` 변수가 함수 전체에서 단일 선언·비섀도잉임을 확인(인터셉트
  호출부가 잘못된 guid를 참조할 위험 없음).
- 라이브 실사는 이 세션 네트워크 제약으로 불가 — 배포 후 gov_do/
  gov_national 소속 SP 하나로 실제 위임(SP_CALL)이 발동하는 시나리오를
  만들어, 최종 응답에 `[AGY_VAULT_STORE]` 태그가 화면에 노출되지
  않는지 + `owner_pdv`에 기록되는지 확인 권장.
