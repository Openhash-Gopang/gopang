# HANDOFF 2026-08-07 · 의사·변호사 세부분야 대폭 확장 계획

> 이 문서는 기존 §5(physician→내과/외과/신경과, lawyer→형사법/민사법/
> 기업법무 각 3개)를 **현실의 공식 분류 기준으로 대폭 확장**하기 위한
> 계획서다. CONSULT_SPECIALIST(동적 자문 호출) 메커니즘과 §6 코드
> (`parentKey` 재귀 조립)는 이미 구현·검증 완료 상태 — 이 문서는
> **SP 콘텐츠 확장 작업만** 다룬다.

## 0. 근거 자료 (2026-08-07 확인)

- **의사**: 「전문의의 수련 및 자격 인정 등에 관한 규정」(대통령령) 제3조,
  law.go.kr 원문 확인. 26개 전문과목 — 1996년(39회 시험)부터 현재 체계
  정착.
- **변호사**: 대한변호사협회 「변호사 전문분야 등록에 관한 규정」 별표1
  (2020.12.28. 개정본 원문 확인, koreanbar.or.kr). 62개 전문분야 —
  변호사 본인이 최근 3년 내 해당 분야 사건 20~30건 수임 실적을 등록
  요건으로 요구하는 실무 기준이라, "현실에 존재하는 수요"를 그대로
  반영한 목록으로 볼 수 있다.

## 1. 의사(physician) — 26개 전문과목

**이미 있음(3개)**: 내과, 외과, 신경과.

**남은 23개**를 임상적 위해도·이용빈도 기준으로 5개 배치로 편성한다
(기존 §7 롤아웃과 동일한 "저위험·고유사성 먼저" 원칙 — 여기서는 "고빈도·
필수과 먼저"로 변형 적용):

### 배치 1 — 고빈도 필수과 (5개)
| 전문과목 | 비고 |
|---|---|
| 소아청소년과 | 성인과 다른 약물 용량·발달 단계 판단 필요 — 내과와 명확히 분리 |
| 산부인과 | 임신·출산 특유의 M1 응급 신호(자간전증 등) 별도 정의 필요 |
| 정신건강의학과 | **주의**: clinical-psychologist·mental-health-professional 페르소나와 경계 설정 필수(약물치료 가능 여부가 핵심 차이 — 의사만 처방 가능) |
| 가정의학과 | 사실상 physician(부모) 자체와 가장 가까움 — 세부분야로 분리할 실익이 낮을 수 있음, §5 H5(최소 신설 기준) 재검토 권고 |
| 응급의학과 | **주의**: paramedic 페르소나와 경계 설정 필수(응급의학과는 병원 내 응급실 의사, paramedic은 병원 전 단계) |

### 배치 2 — 수술계 (4개)
| 전문과목 | 비고 |
|---|---|
| 정형외과 | physician-surgery(일반외과)와 구분 — 근골격계 특화 |
| 심장혈관흉부외과 | 심장·대혈관·흉부 — M1 응급도 최고 수준(급성 대동맥박리 등) |
| 성형외과 | 미용 목적과 재건 목적 구분 필요(전자는 광고성 정보 편향 위험 — C 조항 재확인) |
| 마취통증의학과 | 수술 마취 + 만성통증 클리닉 두 축 — 세부분야를 더 쪼갤지 여부 검토 필요 |

### 배치 3 — 감각·피부·비뇨 (4개)
| 전문과목 | 비고 |
|---|---|
| 안과 | optician(안경사) 페르소나와 경계 — 안경사는 검안·조제, 안과는 질환 진단 |
| 이비인후과 | |
| 피부과 | hairdresser 페르소나와 경계(미용 시술 vs 피부질환 치료) |
| 비뇨의학과 | |

### 배치 4 — 영상·검사·특수 (6개)
| 전문과목 | 비고 |
|---|---|
| 영상의학과 | radiologic-technologist(방사선사) 페르소나와 경계 — 방사선사는 촬영, 영상의학과는 판독·진단 |
| 방사선종양학과 | 암 방사선치료 — 종양내과적 판단과의 경계 필요(종양내과는 별도 세부과목 없음, 내과 산하) |
| 병리과 | medical-lab-technologist와 경계(검체 처리 vs 최종 병리 진단) |
| 진단검사의학과 | 상동 |
| 핵의학과 | PET 등 특수 영상 — 영상의학과와 겹치는 부분 조율 필요 |
| 결핵과 | **저빈도 — 사실상 유명무실화**(신규 전공의 배출 없음, 실질적으로 내과에 흡수). 제외 권고 |

### 배치 5 — 재활·예방·직업환경 (4개)
| 전문과목 | 비고 |
|---|---|
| 재활의학과 | physical-therapist(물리치료사) 페르소나와 경계 — 재활의학과는 처방·진단, 물리치료사는 시행 |
| 예방의학과 | health-educator(보건교육사)와 경계 |
| 직업환경의학과 | industrial-safety-consultant(산업안전지도사)와 경계 — 의학적 진단 vs 안전관리 |

**총 22개 신설 권고**(결핵과 제외) + 배치1의 가정의학과는 §5 H5 재검토
대상으로 별도 표시.

## 2. 변호사(lawyer) — 62개 전문분야

**이미 있음(3개, 근사 매핑)**: 민사법, 형사법, lawyer-corporate(≈회사법+
인수합병 통합).

**타 페르소나와 중복 — 신설 제외(12개)**:

| 전문분야 | 중복 대상 페르소나 |
|---|---|
| 노동법, 산재 | labor-attorney(공인노무사) |
| 조세법, 법인세, 상속증여세, 국제조세 | tax-accountant(세무사) |
| 관세 | customs-broker(관세사) |
| 지적재산권법, 특허, 상표, 저작권, 영업비밀 | patent-attorney(변리사) |

이 12개는 변호사도 법적으로 다룰 수 있는 영역이지만, **이 플랫폼은
이미 그 실무를 전담하는 별도 자격직 페르소나를 두고 있다** — 중복
신설하면 라우팅 혼란(사용자가 "노동법 상담"이라고 했을 때 labor-attorney와
lawyer-labor 중 어디로 갈지)과 콘텐츠 이원화(같은 주제를 두 SP가 따로
관리)가 생긴다. 대신 lawyer-corporate 등 관련 세부분야의 IDENTITY
경계 문단에서 "이 영역은 OO 페르소나로 연계"를 이미 하듯, 나머지도
동일 패턴을 따른다.

**남은 47개**를 실제 분쟁 빈도·이 플랫폼 사용자층(개인 이용자 중심)
기준으로 4개 배치로 편성한다:

### 배치 1 — 개인 생활분쟁 고빈도 (8개)
가사법, 이혼, 상속, 부동산, 임대차관련법, 교통사고, 손해배상, 등기·경매

*(이혼/가사법/상속 3개는 서로 밀접 — 통합 여부 검토: 예를 들어
"가사법" 하나로 이혼·상속·소년법까지 포괄할지, 개별 유지할지는 §5
H5 기준으로 착수 시 재확인)*

### 배치 2 — 기업·상거래 (10개)
상사법, 회사법·인수합병(기존 lawyer-corporate와 통합/재조정 필요),
민사집행, 채권추심, 도산, 증권, 금융, 보험, 국가계약, 공정거래

### 배치 3 — 형사 관련 확장 + 행정 (7개)
군형법, 소년법, 행정법, 헌법재판, 환경, 수용 및 보상, 식품·의약

### 배치 4 — 국제·신산업·기타 (저빈도, 22개)
해상, 무역, 조선, 중재, IT, 방송통신, 에너지, 국제관계법, 국제거래,
국제중재, 이주 및 비자, 해외투자, 스포츠, 종교, 성년후견, 스타트업,
학교폭력, 입법, 엔터테인먼트(지재권 제외분), 건설, 재개발·재건축

*(이 배치는 항목이 많고 개별 수요가 낮아, 실제 착수 여부를 배치1~3
완료 후 재논의 권고)*

## 3. 공통 설계 원칙 (기존 §5 그대로 적용)

각 신규 자식 SP는 §5 규칙대로 다음만 담는다 — 그 이상은 금지:
1. 세부분야 경계 문단(인접 세부분야·타 페르소나와의 경계 — 위 표의
   "비고"가 그 재료)
2. Tier 테이블(그 분야 특유 환각 위험)
3. L2·L3 심화 모듈
4. STEP R 3훅(변호사) 또는 STEP R-1v 자문호출 훅 확장

부모 SP(physician/lawyer)의 STEP R-1v(자문호출 판단기준) 소절에도
새 자식이 생길 때마다 "언제 이 자식을 부르는가" 한두 문장씩 추가해야
한다 — 지금 3개 기준으로 쓰인 판단기준 목록이 자식 수만큼 늘어난다.

`getConsultableChildren('physician')`/`getConsultableChildren('lawyer')`가
자동으로 새 자식을 인식하므로(레지스트리 등록만 하면 CONSULT_SPECIALIST가
즉시 그 자식을 호출 대상으로 인정) 코드 변경은 필요 없다 — SP 콘텐츠
작성 + `expert-registry.js`/`sp-catalog.json` 등록만 하면 된다.

## 4. 실행 순서 제안

1. **의사 배치 1(5개)** — 고빈도 필수과, 다른 기존 페르소나와의 경계가
   가장 많이 걸리는 배치라 먼저 처리하며 경계 설정 패턴을 확립.
2. **변호사 배치 1(8개)** — 개인 생활분쟁, 이 플랫폼 사용자층에 가장
   직접 와닿는 영역.
3. 이후 배치는 앞선 배치에서 확립된 패턴을 참고해 순차 진행 — 매 배치
   완료 시 §6 회귀 테스트(`expert-base-composition.test.mjs`) 재실행,
   catalog 고아참조 스캔 필수(지난 세션에서 실제로 발생했던 사고 재발
   방지).
4. 착수 전 다음 열린 질문을 먼저 확정할 것:
   - 가정의학과를 세부분야로 분리할지, physician(부모) 자체로 흡수할지
   - 이혼/가사법/상속을 개별 유지할지 통합할지
   - 배치4(국제·신산업, 22개)는 실제로 착수할지, 스코프에서 뺄지
