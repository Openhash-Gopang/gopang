## 0. 최우선 원칙 — "첫날부터 흑자, 절대 적자 아님"

이 문서 전체를 관통하는 단 하나의 제약 조건:

> **어떤 가입자가 어떤 방식으로 쓰더라도, 그 가입자에게서 걷는 수입이 그 가입자가 유발하는 원가보다 낮아지는 경우는 구조적으로 존재해서는 안 된다.**

성장이나 확산보다 이 조건이 우선합니다. 원가가 수입을 초과하는 상황이 단 한 명에게서라도 반복되면, 가입자 수가 늘어날수록 손실이 커지는 구조가 되어 사업 존속 자체를 위협합니다(요청하신 문제의식과 동일). 따라서 아래 모든 티어는 **"정액 요금 + 사용량 상한(FUP) + 상한 초과분 자동 종량 전환"** 구조로 설계했습니다 — "무제한"이라는 표현은 어디에도 쓰지 않습니다.

### 0-1. 안전장치의 작동 원리

1. 각 요금제는 정액 요금에 **월간 사용량 상한**(일상대화 건수, SP위임 건수 등)이 딸려 있습니다.
2. 상한은 **"정액 요금 안에서 발생 가능한 최대 원가"가 항상 정액 요금보다 낮도록** 역산해서 정했습니다(아래 §2 각 티어 표의 "최대 원가" 행 참조).
3. 상한을 넘는 사용량은 자동으로 GDC 종량제(기존 `GDC_CHARGE_MANUAL_v1_0.md`의 원가×2 정책)로 전환되어 잔액에서 차감됩니다 — 무료로 계속 쓸 수 없고, 서비스가 끊기지도 않습니다.
4. EXPERT 자문·K-Law 판결예측처럼 원가가 높은 항목은 **정액 요금에 기본 포함하지 않고**, `K_SERVICE_MONETIZATION_v1_0.md`에 이미 정의된 건당 가격을 그대로 유지합니다(일부 상위 티어에 한해 "월 N건 쿠폰"만 얹습니다 — 쿠폰 원가도 상한 계산에 포함되어 있습니다).
5. 이 상한은 초안이며, 실사용 분포를 확인할 때까지는 **보수적으로(=낮게)** 잡았습니다. 실측 후 상향 조정하는 것은 안전하지만, 사전에 낙관적으로 높게 잡는 것은 위험합니다.

## 1. 한국 소득 수준 대비 가격 포지셔닝

한국은행 발표(2026-03-10) 기준 2025년 1인당 GNI는 **연 5,241.6만원 (월 평균 약 436.8만원)**입니다.

| 가격 | 월 1인당 GNI 대비 비중 |
|---|---|
| ₩990 | 0.0227% |
| ₩1,990 | 0.0456% |
| ₩2,990 | 0.0684% |
| ₩9,900 (기존 Tier 2-프로) | 0.227% |

세 요금제 모두 "소득 대비 의사결정이 필요 없는 가격"(편의점 군것질 수준)입니다. 이는 `K_SERVICE_MONETIZATION_v1_0.md`가 이미 명시한 원칙 — "혼디 기본요금은 그대로 저렴하게 유지, 확산이 최우선" — 과 정합적입니다. 진입장벽을 0에 가깝게 만들어 가입 자체에 대한 고민을 없애고, 실제 수익은 EXPERT·K-Law 같은 고가치 개별 상품과 상위 티어(프로)에서 확보하는 구조입니다.

## 2. 3단계 요금제 설계

원가 단가는 `BUSINESS-PLAN.md` §2-2(DeepSeek V4 기준, 2026-07-09 문서화)를 사용합니다. A=일상대화(₩0.08/건), B=단순 SP위임(₩0.36/건), C=EXPERT 자문(₩6/건).

### 2-1. 라이트 — ₩990/월

| 포함 항목 | 월 상한 |
|---|---|
| 일상대화(A) | 3,000건 (하루 약 100건) |
| 단순 SP위임(B) | 30건 |
| EXPERT/K-Law | 미포함 — 건당 별도 결제 |

- **최대 원가**: 3,000×₩0.08 + 30×₩0.36 = ₩250.8
- **최소 마진**: (990−250.8)/990 = **74.7%**
- **타깃**: 학생, 시니어, 처음 써보는 라이트 유저 — "일단 가입해서 일상 민원·잡담 정도만 써본다"

### 2-2. 베이직 — ₩1,990/월

| 포함 항목 | 월 상한 |
|---|---|
| 일상대화(A) | 10,000건 |
| 단순 SP위임(B) | 100건 |
| EXPERT 자문(C) 쿠폰 | 1건/월 (시중가 3,000~5,000원 상당을 무료 제공) |

- **최대 원가**: 10,000×₩0.08 + 100×₩0.36 + 1×₩6 = ₩842
- **최소 마진**: (1,990−842)/1,990 = **57.7%**
- **타깃**: 일반 직장인 — 일상 사용 + 가끔 전문 상담 필요층

### 2-3. 플러스 — ₩2,990/월

| 포함 항목 | 월 상한 |
|---|---|
| 일상대화(A) | 20,000건 |
| 단순 SP위임(B) | 200건 |
| EXPERT 자문(C) 쿠폰 | 2건/월 |
| K-Law 판결예측 할인쿠폰 | 10% 할인 1장 (원가 부담 없음 — 사용자가 여전히 대부분 결제) |

- **최대 원가**: 20,000×₩0.08 + 200×₩0.36 + 2×₩6 = ₩1,684
- **최소 마진**: (2,990−1,684)/2,990 = **43.7%**
- **타깃**: 자영업자·소상공인 — 민원·서류·전문 자문을 자주 쓰는 헤비 유저

### 2-4. 프로 — ₩9,900/월 (기존 유지, 재정의)

| 포함 항목 | 월 상한 |
|---|---|
| 일상대화(A) | 100,000건 |
| 단순 SP위임(B) | 1,000건 |
| EXPERT 자문(C) 쿠폰 | 5건/월 |
| K-Law 판결예측 할인쿠폰 | 20% 할인 2장 |

- **최대 원가**: 100,000×₩0.08 + 1,000×₩0.36 + 5×₩6 = ₩8,390
- **최소 마진**: (9,900−8,390)/9,900 = **15.3%**
- **타깃**: 사업자, 매우 헤비한 파워유저. 절대 마진(₩1,510/인)은 낮은 티어보다 크므로 문제 없음.

### 2-5. 요약 비교

| 티어 | 가격 | 최대 원가 | 최소 마진율 | 절대 마진 |
|---|---|---|---|---|
| 라이트 | ₩990 | ₩250.8 | 74.7% | ₩739 |
| 베이직 | ₩1,990 | ₩842 | 57.7% | ₩1,148 |
| 플러스 | ₩2,990 | ₩1,684 | 43.7% | ₩1,306 |
| 프로 | ₩9,900 | ₩8,390 | 15.3% | ₩1,510 |

상위 티어로 갈수록 마진율(%)은 낮아지지만 절대 마진(원)은 커지는 구조 — 일부러 이렇게 설계했습니다. 상위 티어는 "박리다매"가 아니라 "많이 쓰는 사람에게 더 낮은 단가를 제공하되, 여전히 흑자"라는 게 목적입니다. **모든 티어에서 최소 마진율이 0% 이상**이므로 §0의 최우선 원칙(첫날부터 흑자)을 만족합니다.

## 3. 출시 전략

### 3-1. 단계적 오픈 (실측 전 전국 동시 오픈 금지)

`BUSINESS-PLAN.md` §5의 원칙("실측 데이터로 교체 필요")을 그대로 따릅니다.

1. **1단계 (제주 필드테스트, 현재)**: 라이트(₩990) 단일 티어만 오픈. 실사용 분포(1인당 월평균 A/B 건수)를 수집.
2. **2단계**: 1단계 데이터로 §2의 상한값을 검증·조정한 뒤, 베이직(₩1,990)·플러스(₩2,990) 오픈.
3. **3단계 (전국 확장)**: 프로(₩9,900) 포함 4단계 전체 오픈 + Tier 3(B2B 광고형) 연동.

각 단계 전환 조건은 "N개월 손익 실측 흑자 확인" — 다음 단계로 넘어가기 전 반드시 실제 마진이 이론치와 크게 어긋나지 않는지 확인합니다.

### 3-2. 손익 모니터링 (필수 — 안전장치의 실행 수단)

이론상 마진이 양수여도, 실제 운영에서 상한 로직이 버그로 새거나(FUP 미적용 등) 캐시 히트율이 가정보다 낮으면 마진이 잠식될 수 있습니다. 다음을 운영 필수 항목으로 둡니다:

- 가입자별 **일별 원가 vs 수입 대시보드** (음수 마진 발생 즉시 알람)
- 캐시 히트율이 §2 가정(80%/50%/30%)보다 낮아지는 경우 자동 경보
- 상한 도달 시 자동 종량 전환이 실제로 작동하는지에 대한 회귀 테스트 (기존 저장소에 `HONDI_MASTER_TEST_PLAN_v1_0.md` 패턴 참조)

### 3-3. 가격 표기 방식

기존 팜플렛 등 홍보물에는 "월 990원부터"처럼 최저가만 노출하고, 실제 가입 화면에서 3단계를 나란히 비교해 보여주는 방식을 권장합니다(카카오톡·통신사 요금제 UI 관례와 동일). 이 문서의 상한값(건수)은 일반 사용자에게는 "일상대화·민원 충분히 무제한급으로 이용 가능"처럼 안내하되, 내부적으로는 반드시 상한을 강제합니다.

## 4. 리스크 및 미확정 항목 (정직하게 남겨둠)

1. **A/B 건수 상한이 실제 사용자 행태와 맞는지 검증되지 않았습니다.** 극단적으로 대화를 많이 하는 소수 이용자가 상한에 자주 걸려 불만이 생길 수 있습니다 — UX상 "상한 도달" 안내 문구 설계 필요.
2. **캐시 히트율 가정(80%/50%/30%)은 `BUSINESS-PLAN.md` §2-2의 가정을 그대로 가져온 것**이며, 실측치가 아닙니다. 히트율이 낮으면 이 문서의 모든 마진율이 낮아집니다.
3. **EXPERT 자문 쿠폰(월 1~5건)의 실제 사용률**: 쿠폰을 아무도 안 쓰면 마진이 더 커지고, 전원이 다 쓰면 계산된 최대 원가와 일치 — 두 경우 모두 안전하지만, 중간값 실측이 필요합니다.
4. **Kimi K3 등 고비용 모델은 이 요금제에 포함되지 않습니다.** `BUSINESS-PLAN.md` §2-4에서 확인했듯, Kimi K3 원가는 이 티어 구조로 감당할 수 없는 수준입니다. 정액 요금제의 기반 모델은 당분간 DeepSeek로 고정합니다.
5. **환율(₩1,400/$1) 변동 리스크**: 원화 약세 시 모든 원가가 비례해서 오릅니다. 상한값은 환율 변동을 반영해 주기적으로 재계산해야 합니다.
