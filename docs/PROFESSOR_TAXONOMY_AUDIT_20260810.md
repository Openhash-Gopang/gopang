# PROFESSOR_TAXONOMY_AUDIT_20260810.md

`docs/PROFESSOR_LEAF_CATALOG_20260810.md`(전체 카탈로그)에 이어, §2-1의 나머지 두 작업 지시 결과.

## §A 표준분류체계 대조 감사 — 범위 제약 고지

`expert-registry-professor.js` 주석이 근거로 삼는 "공공데이터포털 「한국대학교육협의회_대학 학과 정보」API 원문(2025년)"을 이 세션에서 직접 내려받아 라인 단위로 대조하는 것은 **불가능했다** — `data.go.kr`/`academyinfo.go.kr`가 이 세션 bash 환경의 네트워크 허용 도메인 목록(`api.anthropic.com`, `github.com`, `npm/pypi` 계열 등)에 없다. 실제 원본 데이터셋과의 학과 단위 전수 대조(예: "소계열 XX가 원본엔 있는데 레지스트리엔 없다")는 이번 세션 범위 밖이다 — 필요하면 사용자가 로컬에서 해당 API를 받아 diff 하거나, 네트워크 허용 목록에 해당 도메인을 추가해줘야 한다.

대신 검색으로 확인 가능한 수준에서 **구조적 커버리지 점검**만 수행:

대학설립운영규정 기준 7대 계열(인문·사회·교육·자연·공학·의약·예체능) 각각에 대응하는 중계열이 28개 안에 존재하는지 확인한 결과, 7개 전부 최소 1개 이상의 중계열로 대응돼 있었다(예: 의약 → 간호/보건/약학/의료/의료예과 5개, 예체능 → 무용체육/연극영화/응용예술/미술/음악 5개). 대분류 단위의 완전공백은 없다 — 다만 이건 "큰 구멍이 없다"는 확인일 뿐, 개별 소계열(전공) 단위의 누락 여부는 위 제약으로 검증 못 했다.

## §B K-12 신설 4개 리프 정합성 검토

4개(`professor-generalmusic`, `professor-classicalchinese`, `professor-generalpractical`, `professor-careereducation`) 전부 SP 파일 헤더에 "K-12 교과-전공 매칭 갭 대응"이라고 스스로 이질성을 명시해뒀다(재구성 아님, 기존 문서 그대로). 다만 개별로 뜯어보면 이질성 정도가 서로 다르다:

| 리프 | 소속 중계열 | 정합성 판단 |
|---|---|---|
| `professor-classicalchinese`(한문학) | `professor-language-literature` | **문제없음**. 한문학과는 실제 대학에 존재하는 정식 학과(예: 성균관대 한문학과) — K-12 갭 대응 목적으로 만들었지만 결과적으로 표준분류체계상의 정규 소계열과 일치한다. 형제 리프(국어·영어·독어·중국어 등)와 급이 같다. |
| `professor-generalmusic`(교양음악) | `professor-music-series` | **급 불일치 가능성**. 형제 5개(성악·작곡·기악·국악·실용음악·음악학)는 전부 대학 "전공" 단위인데, 이것만 "교양" 과목 단위다 — 대학에서 "교양음악"은 보통 학과명이 아니라 비전공자 대상 교양 과목명이다. §1-1에 보고된 라우팅 불안정(리코더 질문이 국악으로 새는 문제)이 바로 이 급 불일치 때문일 가능성이 있다 — 게이트 후보 목록에서 구체적 전공명들 사이에 추상적 과목명 하나가 끼어 있으면 밀릴 수 있다는 가설. 다음 라우팅 튜닝 시 "레이블을 더 구체화"보다 "이 리프의 급 자체가 형제들과 다르다"는 관점에서 접근해볼 가치가 있다. |
| `professor-generalpractical`(교양 기술·가정) | `professor-misc-series` | 이질성 부담 낮음 — `misc-series`(기타 N.C.E, 잡다한 항목을 모아두는 버킷) 소속이라 애초에 이 그룹 안에서는 "정식 학과 단위"라는 전제 자체가 약하다. |
| `professor-careereducation`(진로교육) | `professor-misc-series` | 이질성 부담 낮음(위와 동일 이유) + **재소속 검토 후보**: "진로진학상담"은 교육대학원에 실재하는 전공(예: 여러 대학 교육대학원 진로진학상담전공)이다 — `professor-misc-series`보다 `professor-education-series`(교육 중계열) 밑이 표준분류체계 관점에서 더 정합적일 수 있다. 라우팅에 지장이 없다면 우선순위는 낮은 리팩터. |

### 요약
4개를 뭉뚱그려 "전부 이질적"으로 보는 건 부정확하다 — `classicalchinese`는 사실상 문제없고, `generalmusic`이 가장 근본적인 급 불일치(§1-1 미해결 라우팅 버그의 구조적 원인일 가능성), `careereducation`은 재소속 검토 대상, `generalpractical`은 버킷 성격상 무해하다.
